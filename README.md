# Crypto Telegram Bot

Телеграм-бот для отслеживания криптовалютного рынка и управления портфелем.  
Данные — CoinGecko (бесплатно, без API-ключа). БД — PostgreSQL.

## Команды

| Команда | Описание |
|---|---|
| `/market` | Топ-20 монет по капитализации с изменением за 24ч |
| `/recommend` | Рекомендации к покупке (анализ топ-100 монет) |
| `/portfolio` | Портфель с текущим P&L |
| `/add btc 0.5 65000` | Добавить 0.5 BTC, куплено по $65000 |
| `/remove 3` | Удалить позицию с ID=3 |

## Быстрый старт

### 1. PostgreSQL

```sql
CREATE DATABASE cryptobot;
```

### 2. Настройка окружения

```bash
cp .env.example .env
# Отредактируйте .env:
# BOT_TOKEN  — токен от @BotFather
# DATABASE_URL — строка подключения к PostgreSQL
# OWNER_ID   — ваш Telegram ID (узнать у @userinfobot)
```

### 3. Запуск

```bash
go run .
# или собрать бинарник:
go build -o crypto-bot .
./crypto-bot
```

## Как работает алгоритм рекомендаций

Каждая монета из топ-100 получает оценку (score) по факторам:

| Фактор | Очки |
|---|---|
| Просадка за 24ч от -5% до -20% | +2 |
| Недельная просадка от -10% до -35% | +2 |
| Далеко от ATH (>60% ниже) | +1 |
| Высокий объём торгов (>15% от капы) | +1 |
| Топ-50 по капитализации | +1 |
| Месячный рост при дневном откате | +1 |

Рекомендуются монеты с score ≥ 2. Стейблкоины исключаются.

> ⚠️ Это не финансовый совет. Всегда проводите собственный анализ.
